# Sicherheit

## Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** über öffentliche Issues, Pull Requests oder Diskussionen.

- Bevorzugt: **GitHub Private Vulnerability Reporting** – im Repository unter *Security* → *Report a vulnerability*.
- Alternativ per E-Mail an **security@synchrothek.de**.

Hilfreich sind: betroffene Version und Browser, Schritte zum Nachvollziehen, mögliche Auswirkungen und – falls vorhanden – ein Vorschlag zur Behebung.

Ich bestätige den Eingang und melde mich mit einer Einschätzung, so schnell es geht. Feste Antwortzeiten kann ich als Einzelperson nicht zusagen. Bitte gib mir Zeit für eine Behebung, bevor du Details veröffentlichst.

## Umfang

- Diese Browser-Extension (Repository `synchrothek/synchrothek`).
- Der selbst hostbare Sync-Server liegt in `synchrothek/synchrothek-server`; Meldungen dazu bitte dort.
- Lücken in den offiziellen Diensten (app.synchrothek.de, api.synchrothek.de, sync.synchrothek.de) bitte ebenfalls über die oben genannten Wege.

## English

Please report vulnerabilities privately via GitHub Private Vulnerability Reporting or to security@synchrothek.de – not in public issues. Response times are best effort.
